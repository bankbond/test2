# 3D Space Flight Simulator

Простий браузерний прототип **реалтайм-симуляції польоту і бою в 3D просторі**.

## Що реалізовано

- Реальний час через `requestAnimationFrame`.
- 3D-координати (`x`, `y`, `z`) для кораблів, лазерів і зірок.
- Перспективна проєкція 3D→2D у Canvas.
- Автономний dogfight AI: пошук найближчої цілі, маневрування, стрільба.
- HUD з позицією, швидкістю, HP та поточною ціллю кожного корабля.
- Керування: пауза/продовження та перезапуск симуляції.

## Як запустити

1. Відкрий `index.html` у браузері.
2. Спостерігай за польотом і боєм у Canvas.
3. Використовуй `Пауза` та `Перезапуск` для керування сценарієм.
