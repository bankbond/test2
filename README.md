# Star Battle Sim

Простий веб-симулятор бою двох космічних кораблів у стилі пригод зі Star Wars.

## Що є в демо

- Два кораблі з параметрами: HP, шкода, шанс криту, шанс ухилення.
- Покроковий режим (`Наступний хід`).
- Автоматичний режим (`Автобій до кінця`).
- Журнал подій із результатами кожного раунду.
- Перезапуск бою однією кнопкою.

## Запуск

1. Відкрий `index.html` у браузері.
2. Натисни `Наступний хід` або `Автобій до кінця`.
3. Після завершення натисни `Перезапуск`.
